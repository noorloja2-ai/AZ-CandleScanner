# Knowledge added in v14.8

The new reference images were used as a pattern catalogue, not as proof of guaranteed accuracy.
The app now recognizes the following visual families and then checks them against context:

## Reversal / rejection families
- Hammer / inverted hammer
- Shooting star / hanging man
- Dragonfly / gravestone doji
- Bullish / bearish engulfing
- Bullish / bearish harami
- Piercing line / dark cloud cover
- Tweezer bottom / tweezer top
- Morning star / evening star
- Three inside up / down
- Three outside up / down
- Bullish / bearish kicker

## Continuation / pressure families
- Bullish / bearish Marubozu
- Three white soldiers / three black crows
- Rising three method / falling three method

## Context learned from the reference examples
- A bullish-looking candle at resistance is not automatically BUY.
- A bearish-looking candle at support is not automatically SELL.
- Lower-wick rejection contributes buyer pressure; upper-wick rejection contributes seller pressure.
- Pattern + support/resistance + trend/momentum agreement receives more weight.
- Doji/spinning-top conditions increase uncertainty and usually produce WAIT until confirmation.
- Breakout/breakdown is stronger after a retest/hold than on the first visual touch.

## Self-learning use
When a strong pressure/pattern setup is produced, its name is stored with the prediction.
Only after the exact future candle closes is the result resolved. The existing learner can then
increase or reduce influence from that setup based on real outcomes. This keeps the new chart
knowledge adaptive instead of permanently assuming every textbook pattern works equally well.
