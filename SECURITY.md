# Security Policy

## Reporting a vulnerability

Please report security issues privately to **anamul00pt@gmail.com**. Do not put
credentials, licence keys, admin tokens, screenshots, or exploit details in a
public GitHub issue.

Include the affected app version, Android version, steps to reproduce, and the
impact. You should receive an acknowledgement within seven days.

## Supported version

Security fixes are provided for the latest published CandleScanner version.
